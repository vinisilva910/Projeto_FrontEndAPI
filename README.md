# Portal Interdimensional — Rick and Morty

Projeto acadêmico de front-end desenvolvido com HTML, CSS e JavaScript puro.

## Como executar
1. Extraia a pasta do projeto.
2. Abra a pasta no Visual Studio Code.
3. Execute o arquivo `index.html` com a extensão Live Server (recomendado) ou abra-o no navegador.
4. É necessário estar conectado à internet para carregar a API e as fontes externas.

## API utilizada
Rick and Morty API: https://rickandmortyapi.com/documentation

Endpoint: https://rickandmortyapi.com/api/character

A API é pública e não exige token para os endpoints utilizados neste projeto.

## Recursos
- Cards criados dinamicamente com `document.createElement()` e `appendChild()`.
- Consumo de dados com `fetch()`.
- Pesquisa por nome.
- Filtros por status e espécie.
- Paginação da API.
- Layout responsivo para celular e computador.

## Estrutura
- `index.html`: estrutura da página.
- `css/style.css`: estilos e responsividade.
- `js/script.js`: integração com API e criação dos cards.
- `parte_teorica.pdf`: explicação teórica do projeto.
- `roteiro_pitch.txt`: roteiro sugerido para o vídeo de apresentação.

## Publicação no GitHub Pages
Crie um repositório público, envie os arquivos desta pasta e, em Settings > Pages, selecione a branch `main` e a pasta `/ (root)`. Salve e aguarde a publicação.
